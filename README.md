#  Тренажёр ЭМО

Тренажёр для печати слов по картинкам. Пользователь проходит страницы с заданиями,
затем видит таблицу с результатами.

## Запуск

Открыть файл "index.html" в браузере. Сборка и сервер не требуются.

## Структура

- index.html — страница с заданиями
- answers.html — таблица ответов
- css/styles.css — общие стили
- js/script.js — логика тренажёра
- img/ — изображения заданий и иконки
